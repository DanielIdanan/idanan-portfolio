# Daniel D. Idanan, Portfolio

React portfolio for BSIT 3C (Gordon College, Olongapo City).

Pages: Home (`/`), About (`/about`), Projects (`/projects`), Contact (`/contact`).
All pages render inside one shared layout (Header + Footer) through React Router's `Outlet`.

## Run it

```bash
npm install
npm run dev      # development
npm run build    # production build
```

## Built with

React, Vite, React Router, GSAP (hero intro), Lenis (smooth scroll), Motion (page transition and button press),
tsParticles (network background), CountUp.js (stat counters).
